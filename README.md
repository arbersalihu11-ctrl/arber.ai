# arber.ai portfolio

Personal portfolio for Arbër Salihu: graphic design, content creation, AI visuals and professional experience.

Live website: https://arber-ai.vercel.app

GitHub: https://github.com/arbersalihu11-ctrl/arber.ai

Plain HTML, CSS and JavaScript. No runtime dependencies, account secrets, database or build process are needed.

## Contents

- 2 original branding projects (DIGITAL HIVE and Rinas’s Scope) and 4 visual concepts
- One video portfolio: 90 Koral Secrets reels, 39 Diverse Academy reels and 5 AI films
- A separate photography gallery: 29 Fashion AI photos and 10 AI Explorations
- About and 9 professional positions
- Local photos, fonts, PDF brand books and 5 AI videos

Video collections open in a full-screen viewer with keyboard controls, arrows and a vertical swipe rail. Instagram videos use official embedded posts on demand and include direct Instagram links if playback is unavailable. AI films play from the original local MP4s. Only the selected video is loaded; previous playback clears when navigating or closing. The optional Reels thumbnail gallery sits within the same video section.

## Preview locally

Run from the repository root:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Open http://127.0.0.1:4173.

## Deploy with Vercel

Import this GitHub repository into Vercel. The checked-in `vercel.json` selects the Other framework, skips installation/build and serves `dist/`.

The sharing metadata uses the production domain above. Site links, media and fonts use portable relative URLs. Updates pushed to the `main` branch are deployed automatically by the connected Vercel project.

This repository contains the portable website and its media assets. Account credentials and environment files are excluded.
